# Code of Conduct

This code applies to project discussions, issue reports, code reviews and other project collaboration.

## Shared expectations

- Respect different backgrounds, experience levels and views. Use friendly, clear language.
- Give constructive feedback grounded in facts and code. Respect others' time and work.
- Harassment, discrimination, threats, personal attacks and disclosure of private information without consent are unacceptable.
- Do not disclose accounts, passwords, keys or personal learning data in public discussions or the repository.

## Reporting and response

Report misconduct through a private contact channel provided by a repository maintainer. Include the time, context and necessary evidence. Avoid exposing private information in public issues. If no private channel is available, first ask a maintainer for contact details.

Maintainers should protect reporters' privacy, establish the facts and respond according to severity with reminders, requests for correction, removal of inappropriate content or participation restrictions. If a maintainer is involved, reports may go to another uninvolved maintainer. Responses should be fair and free of retaliation.

# 行为准则

本准则适用于项目讨论、问题反馈、代码审查及其他项目协作活动。

## 共同约定

- 尊重不同背景、经验和观点，使用友善、清晰的语言。
- 围绕事实与代码提出建设性意见，尊重他人的时间与劳动。
- 不接受骚扰、歧视、威胁、人身攻击或未经同意公开他人隐私。
- 不在公开讨论或仓库中披露账户、密码、密钥和个人学习数据。

## 反馈与处理

遇到不当行为，请通过仓库维护者提供的私下联系渠道报告，说明发生的时间、场景与必要证据。避免在公开 issue 中暴露隐私；尚无私下渠道时，可先请求维护者提供联系方式。

维护者应保护报告者隐私，核实情况，并根据严重程度采取提醒、要求更正、移除不当内容或限制参与等措施。涉及维护者本人时，可向其他未涉事维护者反馈；处理应公平且避免报复。
